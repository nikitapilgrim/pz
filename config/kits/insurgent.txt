# Kit for characters whose profession id contains "insurgent" (the file name). Dropped automatically next to a
# new character by the server (scripts/pz_kits.lua), or given by hand: docker compose run --rm pz-kit <username>
#
#   <Module.ItemId> [count]                                   always given
#   pick <group>: <Module.ItemId> [count], <Module.ItemId> [count], ...
#       one line per option; one option per group is chosen at random. The first item is the main one (the
#       weapon): if the game does not know it (mod disabled, wrong ID), another option of the group is used.
#
# IDs come from the game's 42.18 item scripts and the mods' own files (VFE, PNV, Signal Smoke). The server log shows
# every unknown ID as "[pz-kit-auto] item ... failed"; pz-kit prints the server's reply for every line. Fix IDs here:
# the folder is mounted, the change applies on the next docker compose up -d (automatic) or right away (pz-kit).
# More IDs: the admin item list in game.
