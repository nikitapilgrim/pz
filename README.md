# Project Zomboid B42 · Project Viewpoint Server 🧟

Выделенный сервер **Project Zomboid Build 42.21** в Docker с модпаком **Project Viewpoint** (игра от 1-го и 3-го лица в 3D) и сюжетным режимом для небольшой компании: **спецназ против подопытных из секретной лаборатории**.

> *Dockerized Project Zomboid B42.21 dedicated server: one `docker compose up` on Windows, macOS or Linux. Project Viewpoint first-person 3D modpack (52 Workshop items), period music on cassettes, two-faction story setup tuned for 1-3 hour sessions.*

- 🐳 **Одна команда на любой системе:** Windows и macOS (Docker Desktop) или Linux. Пароли, конфиги, права и моды контейнер готовит сам.
- 🎮 **B42.21** (ветка Steam `public`), 52 мода из Workshop. Mod ID и зависимости 41 мода сверены с `mod.info` на тестовом сервере, добавленные позже — по описаниям в Workshop. Списки «Required items» из Steam сверены для 50 модов, у двух оставшихся требования взяты из `mod.info` на GitHub и из описания.
- 🔫 **Спецназ со снаряжением:** новому персонажу с профессией Insurgent сервер сам выдаёт комплект: случайные автомат и пистолет (бывают бесшумные), ПНВ, сигнальный дым. Оружейный пак Vanilla Firearms Expansion добавляет ~40 стволов.
- 🚁 **Вертолёты и поставки:** вертолёт виден в 3D и прилетает в среднем раз в ~1,5 часа игры; по рации можно заказать военный ящик, а вертолёты снабжения иногда разбиваются (Military Drop).
- ⏱ **Настроен под 1–3 часа игры в день:** частые события, быстрый опыт и чтение, меньше рутины с едой и сном, базу не разграбят, пока хозяин офлайн.
- 📼 **Музыка эпохи:** 100+ микстейпов, 800+ песен до июля 1993 года, звук «как с кассеты». Играют с бумбокса, из машины, по радио и из музыкального автомата.
- 🔒 **Закрытый сервер для друзей.** Его нет в списке серверов, вход по паролю, пароли генерируются при первом запуске.
- ⚙️ **Настройки сервера и мира** лежат шаблонами в `config/`. Ключи и значения сверены с файлами самой игры 42.21.
- 💾 Бэкап, восстановление и переезд на другую машину — одной командой.

## Требования

| | Минимум | Рекомендуется |
| --- | --- | --- |
| Система | Windows 10/11 или macOS с [Docker Desktop](https://www.docker.com/products/docker-desktop/); Linux с Docker Engine | Ubuntu 24.04 для сервера 24/7 |
| Docker Compose | 2.24+ (есть в любом свежем Docker) | — |
| Память, доступная Docker | 4 ГБ (на пределе) | 8–16 ГБ |
| CPU | 2 ядра | 4 ядра |
| Диск | 25 ГБ | 30+ ГБ SSD |

- **Docker Desktop отдаёт Docker половину памяти компьютера.** ПК на 16 ГБ даёт 8 ГБ, а настройки по умолчанию рассчитаны ровно на 8. Если памяти меньше, см. таблицу в [`.env.example`](.env.example). Сервер и сам предупредит в логе `pz-init`, если памяти не хватает.
- **Место:** игра ~7,2 ГБ, моды ~3,4 ГБ (из них ~1,25 ГБ музыка), образ ~0,5 ГБ. Сверху растут мир и бэкапы. Игрокам при первом входе тоже придётся скачать ~3,4 ГБ модов.

## Запуск

### Windows

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/) и запустите его. При установке оставьте галочку «Use WSL 2». Значок кита в трее должен стать зелёным.
2. Скачайте проект: на GitHub нажмите **Code → Download ZIP** и распакуйте, например, в `C:\pz`. Или `git clone https://github.com/nikitapilgrim/pz.git`.
3. Откройте папку проекта в Проводнике, кликните в адресную строку, наберите `powershell` и нажмите Enter.
4. Введите:
   ```powershell
   docker compose up -d --build
   ```
5. **Первый запуск долгий, 20–40 минут.** Команда ждёт, пока `pz-init` скачает ~3,4 ГБ модов, потом сервер скачает саму игру (~7 ГБ) и создаст мир. За процессом можно следить в отдельном окне:
   ```powershell
   docker compose logs -f pz-init     # подготовка и пароли
   docker compose logs -f pz-server   # сервер; готов, когда появится SERVER STARTED
   ```
6. **Автозапуск:** Docker Desktop → Settings → General → «Start Docker Desktop when you sign in». Сервер поднимется сам после включения ПК.

### Linux (Ubuntu)

```bash
curl -fsSL https://get.docker.com | sudo sh        # Docker Engine + Compose
git clone https://github.com/nikitapilgrim/pz.git && cd pz
sudo docker compose up -d --build
sudo docker compose logs -f pz-server              # ждать SERVER STARTED
```

Автозапуск работает сам: Docker стартует вместе с системой, а сервер поднимается вместе с Docker.

### Пароли

Пароли генерируются при первом запуске и сохраняются вместе с миром:
```bash
docker compose run --rm pz-init passwords
```
- **Server password** нужен друзьям для входа.
- **Admin** — логин `admin` и пароль администратора для хозяина сервера.

Задать свои пароли можно в `.env` (см. `.env.example`).

> ⚠️ **`docker compose down -v` удаляет мир, аккаунты и скачанную игру** (тома `pz_pz-data` и `pz_pz-files`). Для остановки используйте `docker compose stop` или `docker compose down` без `-v`.

## Как друзьям подключиться

**1. Сеть: путь от друзей до сервера.**
- **Сервер в облаке (VPS).** Откройте входящие **UDP 16261 и 16262** в фаерволе (группе безопасности) провайдера. Адрес для друзей — IP сервера. `ufw` порты Docker'а не фильтрует.
- **Сервер дома, проще всего:** [Radmin VPN](https://www.radmin-vpn.com/ru/), бесплатный. Хозяин и друзья ставят его, хозяин создаёт сеть, друзья вступают. Адрес для друзей — Radmin-IP хозяина (`26.x.x.x`).
- **Сервер дома, через роутер.** Пробросьте **UDP 16261 и 16262** на компьютер с сервером и разрешите Docker доступ к сети, когда Windows спросит. Работает только с «белым» IP от провайдера.
- Хозяин на том же компьютере подключается к `127.0.0.1`.

**2. В игре** (каждый игрок):
1. **Ветка игры.** Steam → Project Zomboid → Свойства → Бета-версии → «Нет» (ветка `public`). Версия должна совпадать с сервером.
2. **ZombieBuddy на клиенте** обязателен для Viewpoint. Поставьте его по инструкции на [странице мода](https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853): установщик или параметр запуска. Когда он спросит про Java-код модов Viewpoint, разрешите.
3. **Моды** игра предложит скачать сама при входе. Модели тела Tomb и подогнанная под них одежда грузятся только при запуске игры. Поэтому после первого входа выйдите в главное меню → Моды и включите там Spongie's Character Customisation, Tomb's Player Body, Tomb's Player Body - Textures [NUDE], Tomb's Player Body - Customisation, Tomb's Player Body - Compatability и Tomb's Player Body - Goth Textures [NUDE]. Затем полностью перезапустите игру. Без этого плащи, куртки и другая одежда «просвечивают» телом. Проверка: если у персонажа нет отдельных пальцев, тело Tomb не загрузилось. Так же включите в главном меню Knox Wildlife: иначе его животные могут выглядеть смятыми или проваливаться в землю. Об этом напоминают приветствие сервера и сообщение в чате раз в час (`SETUP_REMINDER_MINUTES` в `server.env`, 0 — выключить).
4. **Вход.** Играть → Присоединиться → Избранное → добавьте адрес сервера, порт `16261` и пароль. В общем списке сервера нет, так и задумано.

## Сюжет и фракции

Цифры взяты из файлов самих модов (`insurgent_characters.txt`, `ImmuneBittenTraits.txt`).

### Спецназ (Black Ops)
- **Спавн:** `[Спецназ] Insurgent Parachute Insertion`, лес у Роузвуда.
- **Профессия `Insurgent`:** +12 очков, бесплатные трейты Highly Trained и Desensitized, опыт Aiming +6, Reloading +6, Fitness +2, Strength +2. Вместе с +4 очками сервера получается 16.
- 🔫 **Снаряжение.** Свою выдачу мода Insurgent (нож, пистолет, комплекты-трейты Rifleman, Assault Trooper…) на нашем сервере не увидели: трейтов-комплектов нет, оружия нет. Автор порта в MP его не тестировал. Поэтому снаряжение выдаёт сам сервер:
  - **Автоматически.** Через несколько секунд после появления нового персонажа с профессией Insurgent рядом с ним падает комплект из [`config/kits/insurgent.txt`](config/kits/insurgent.txt), один раз на персонажа. Это серверный скрипт: игрокам ставить ничего не нужно.
  - **Оружие выпадает случайно**, каждое с тремя магазинами и патронами:
    - основное: M16, карабин CAR-15 (VFE) или **MP5SD со встроенным глушителем** (VFE);
    - пистолет: M9, Mk 23 SOCOM (VFE) или **Mk2-SD со встроенным глушителем** (VFE);
    - если ствол из мода недоступен (мод отключён), автовыдача берёт другой вариант из той же группы, так что магазинов без оружия не будет. Ручной `pz-kit` выбирает вслепую и покажет ошибку сервера.
  - 🌙 **ПНВ:** монокуляр AN/PVS-14 эпохи (мод PNV) и 2 батарейки. Батарейку вставляют правой кнопкой по ПНВ в инвентаре, включают клавишей `V`. Одной хватает на 12 игровых часов, это полчаса реальной игры. Правой кнопкой ПНВ переносится на шлем и откидывается вверх-вниз.
  - **Сигналы (Signal Smoke):** зелёная дымовая шашка, чтобы отметить место, и 2 химсвета на ночь.
  - **Снаряжение:** нож, армейская рация (по ней же заказывают ящики Military Drop), бронежилет, шлем, рюкзак ALICE, 4 бинта.
  - **Одежду Insurgent** (шлем, берет, противогаз, куртку, штаны, бронежилет, ALICE, перчатки) мод даёт выбрать при создании персонажа. В MP это не проверено.
  - **Глушители.** В ванильной B42 их нет. Бесшумные стволы есть только во VFE (MP5SD и Mk2-SD выше); навесной глушитель для M16 и M9 даёт отдельный мод Improvised Silencers, в сборку он пока не входит.
  - **Свой состав:** файл [`config/kits/insurgent.txt`](config/kits/insurgent.txt). Строка `Модуль.ID [количество]` выдаётся всегда, строки `pick группа: ID, ID кол-во, …` — по одному случайному варианту на группу. ID видно в админ-списке предметов.
  - **Вручную**, если нужно: `docker compose run --rm pz-kit ИмяИгрока`.
  - **Проверить, не мешает ли Dynamic Traits** трейтам самого Insurgent: в `.env` добавить `MODS_DISABLED=DynamicTraits;MoodleFramework`, выполнить `docker compose up -d` и создать нового персонажа.
- ⚠️ **Правило: спецназ не берёт `Immune` и `Bitten`.** Механически это не запрещено: Immune стоит всего 8 очков, а пара Immune + Bitten даже добавляет 6. Стоимость зашита в мод. Правило держится на договорённости, его напоминает приветствие сервера.
- 🪚 **Укус = гонка с ампутацией** (The Only Cure+, с 5 ноября 2026 вместо The Only Cure; старые сохранения работают):
  - Время до смерти выпадает случайно, от 0 до 12 игровых часов. При часовом дне это 0–30 реальных минут, затем мгновенное восстание.
  - Отпилить укушенную руку или ногу, пока инфекция ниже 20% (настройка `TOC.CureWindow`), значит вылечиться наверняка. Это окно **0–6 минут, в среднем ~3**. От 20% до 40% (`TOC.LateGambleWindow`) ампутация — лотерея, позже не поможет.
  - Операция идёт по шагам: осмотр раны, дезинфекция, разрез, распил, шов, бинт. Шансы видны заранее. Медики умеют сами, остальным нужна книга Field Surgery Guide. Обезболить можно снотворным, без него крик слышен на 25 клеток.
  - После операции: шок, восстановление (5 игровых дней), фантомные боли и сепсис, если культю не держать чистой и перебинтованной.
  - Протезы: верстак (Плотничество 3), 5 основ от деревянной до кибернетической и 7 насадок (крюк, механическая кисть, бензопила, штык…). Протезы изнашиваются и чинятся. Без ноги — костыль или ползком.
  - Зомби, которому сильно ударили по ноге, может стать ползуном.
  - Корпус, шею и голову ампутировать нельзя. Царапины не заражают.

### Подопытные (лаборатория)
- **Спавн:** `[Лаборатория] Secret Research Base`, бункер у Роузвуда. В моде три стартовые комнаты, игра выбирает одну случайно.
- **Обязательные трейты:** `Bitten` (+14, старт с укусом) и `Immune` (стоит 8, иммунитет к превращению). С Unemployed (+8) и +4 сервера получается 18 свободных очков.
- 🩹 На старте укус перевязан (`BittenStartBandaged`). По словам автора мода, без этого открытая рана высасывает здоровье и персонаж может истечь кровью сразу после появления.
- Задача — выжить и дождаться прорыва спецназа.

## Настройки мира

Полный список — в [`config/SandboxVars.lua`](config/SandboxVars.lua). Каждое отличие от стандарта B42 там подписано комментарием «почему».

| | Как настроено |
| --- | --- |
| Сутки | 1 час реального времени (до 5 ноября 2026 было 2 часа); без игроков время стоит. За вечер в 1–3 часа проходит 1–3 игровых дня |
| Голод, жажда, усталость | растут медленнее обычного («медленно»): меньше рутины в короткой сессии |
| Опыт и книги | ×3,5 (`MultiplierConfig.Global`); книга читается ~22 секунды; +4 очка трейтов всем |
| Зомби | численность растёт со стандартной B42 до ×2 к 28-му игровому дню (≈ 28 часов игры) и дальше не растёт. Респаун «нормальный», как в пресете игры: в местах, где 16 игровых часов (≈ 40 минут игры) никого не было, раз в 3 игровых дня (≈ 3 часа игры) появляется до 10% целевой численности, но не больше неё; зачищенный город заполнится примерно за 30 игровых дней. Скорость случайная, как в стандартной B42: шаркуны (медленные и быстрые) и около 5% спринтеров (`SprinterPercentage = 5`); обычные зрение, слух и память; двери не открывают, но выбивают |
| Заражение | только укусы; смерть через 0–12 игровых часов; восстание мгновенное |
| Монстры Silent Hill | **в тумане, днём и ночью** (больше в густом, меньше в лёгком) и редко; не заражают; Пирамидоголовый включён, тоже редкий. Привязать их к лабораториям мод не умеет |
| Рейдеры (Bandits NPC) | частота авторская (`Bandits.General_SpawnMultiplier = 1.0`): мод раз в 10 игровых минут выбирает одного случайного игрока на весь сервер, так что группе из 2–5 человек это ≈ 0,7 нападения за игровой день (1–4 бандита в начале) плюс бродячие банды (реднеки 5–16, падальщики 5–30), которые ходят между 33 городскими точками. Машины не портят; вламываются, воруют, выключают генераторы, ломают постройки и грядки. Меткость средняя. Подкрепление по рации — 3 бойца через 1–3 минуты (ночью и в непогоду 2–4). Значка прибытия и счётчика убийств нет: замечайте их по голосам, фонарям и выстрелам. Тонкие поправки к кланам и бойцам можно вписать в `config/bandits/bandits.txt` (сейчас пустой), `pz-init` кладёт его в `Lua/bandits/` сервера. Настройка «чаще в городах» в коде мода 42.21 отключена |
| 🚐 Дома на колёсах | Nomad и Dale's Chieftain (с 5 ноября 2026), только в неоткрытых частях карты: парки трейлеров, кемпинги, парковки, фермы, пробки. Nomad вдвое чаще авторского (`GridRV.SpawnRate = 200`), готовая броня для него редко попадается в гаражах и ангарах. Админ: `/addvehicle Base.GridRV Ник`, `/addvehicle Base.DaleChieftainRV Ник` |
| 🔊 Звуковые события | Reactive Sound Events: событие раз в 1–4 игровых дня (≈ 1–4 часа игры), сцены ближе к городам и дорогам |
| 🐻 Дикие звери | Knox Wildlife: чёрные и бурые медведи, лоси, кабаны, койоты, рыси; взрослые хищники и кабаны нападают и на зомби, и на игроков; койоты съедают трупы зомби вместе с лутом |
| Сигнализации | в домах «иногда», зомби их тоже включают; в машинах «иногда» |
| 🚁 Вертолёты | событие игры «часто»: раз в 7–10 игровых дней (7–10 часов игры), с несколькими заходами. Сверху серверный скрипт: облёт случайного игрока днём в среднем раз в 1,5 игровых дня (≈ раз в 1,5 часа игры); это та же команда, что админская `/chopper`, по таймеру. Каждый заход шумит и стягивает зомби до 500 клеток вокруг |
| 📦 Военные поставки | Military Drop: частоту и код ищут в записках военных и полицейских зомби (код меняется раз в две игровые недели), ящик заказывают с военной рации. Один ящик на весь сервер раз в 3 игровых дня (≈ 3 часа игры), падает в 150–400 клетках от вызвавшего, под охраной орды |
| 💥 Крушения | разбивается в среднем 1 вертолёт снабжения из 5, в грозу чаще: обломки с запчастями, тело пилота с документами, бортовой самописец, а заказ уцелел. Чужой вертолёт снабжения можно сбить стрельбой (PvP) |
| Дальние события | выстрелы вдали и другие «мета-события» — «часто» |
| Находки | сюжетные дома (тайники, сгоревшие, баррикады), дорожные и лесные истории — «иногда» вместо «редко» |
| Лут | огнестрел и патроны ×2 к норме, медицина ×1,7 (там же протезы, костыли, пилы и книга Field Surgery Guide из The Only Cure+), холодное оружие ×1, остальное стандарт B42; обновляется раз в игровую неделю |
| Машины | почти не заперты, бензин есть, расход −30% |

### ⏱ Под 1–3 часа игры в день
- **Часто что-то происходит:** вертолёт в среднем раз в ~1,5 часа игры, военный ящик не чаще раза в ~3 часа игры, задания штаба Military Drop (разведка, зачистка, проверка связи), дальние выстрелы, сигнализации, больше сюжетных находок.
- **Меньше рутины:** голод, жажда и усталость растут медленнее, сон не обязателен, опыт ×3,5, книга читается ~22 секунды, карта открыта. Убежище защищено от игроков, пока вы офлайн, и не отнимается после недели без игры. Без игроков время стоит.
- **Зомби возвращаются, но медленно и до потолка:** зачищенное место остаётся чистым, пока там бывают. Учтите: время «без присмотра» идёт, пока в игре хоть кто-то. Если друг два часа играет в другом конце карты, возле вашей базы могут появиться зомби; от зомби убежище не защищает. Плотность растёт до ×2 к 28-му игровому дню, а вертолёты и дальние выстрелы стягивают зомби. Если станет тяжело или сервер начнёт тормозить, снизьте `PopulationPeakMultiplier` в `config/SandboxVars.lua`.
- **Сутки часовые** (с 5 ноября 2026, по просьбе игроков; до этого были 2-часовыми ради ампутации). Окно, когда The Only Cure+ ещё наверняка спасает укушенную руку или ногу, теперь 0–6 минут, в среднем ~3 (было ~6). Еда, жажда и усталость считаются по игровому времени, поэтому в реальном времени есть и пить придётся вдвое чаще, а вертолёты, военные ящики и респаун зомби приходят вдвое чаще.
- **Регуляторы:** если зомби от вертолётов слишком много, увеличьте `HELI_FLYOVER_DAYS` в `.env` (3 = вдвое реже, 0 = без облётов); если вертолётов мало, поставьте 1.

### 📼 Музыка (True Music + Mixtape Megapack)
- **Mixtape Megapack** раскладывает по миру больше 100 кассет-микстейпов, каждая примерно на 30 минут. Внутри больше 800 песен разных жанров: классический рок, гранж, хип-хоп, кантри, диско, метал, нью-вейв, R&B и другие.
- Всё вышло до июля 1993 года, то есть до начала игры. Треки сведены «под кассету», со звуком магнитофона в начале и конце.
- Кассеты играют на бумбоксе (на батарейках) и в кассетнике любой машины. Проигрыватель пластинок тоже есть, но пластинок в этом паке нет: автор обещает их отдельным модом.
- **Радио:** 5 станций True Music крутят песни из всех подключённых паков, плюс канал MTV. Плейлисты меняют терминалы на радиостанции в западной части Риверсайда.
- **Музыкальный автомат** вмещает сотни кассет и пластинок. В MP все рядом слышат одну и ту же песню.
- Бумбокс и колонки слышат все рядом. Ручное радио в MP слышит **только владелец**.
- Громкая музыка приманивает зомби. Для радио приманивание по умолчанию выключено.
- ⚠️ True Music B42 — неофициальный порт. В MP на 42.20 у него были баги: кассеты залипали или дублировались, музыка продолжала играть после выключения. Готового фикса в виде мода из Workshop нет: «Pack Maker & Bug Fix» — это программа для компьютера, а не мод.

### Viewpoint 0.1.7

Сейчас в Workshop Viewpoint 0.1.6.1 (от 15 октября). Ни даты выхода 0.1.7, ни списка изменений для аддонов пока нет. Сервер при каждом перезапуске качает обновления модов, поэтому 0.1.7 придёт без предупреждения. Что известно по файлам модов (проверено 4 ноября 2026):

- **Переключится само.** В 0.1.7 встроен Isometric No More, а основной QOL требует именно 0.1.7. `scripts/server.sh` читает версию скачанного Viewpoint. Пока это 0.1.6.x, он грузит `ProjectViewpointQOLLegacy0.1.6` и Isometric No More. Начиная с 0.1.7 он грузит `ProjectViewpointQOL` и убирает Isometric No More. Скачать обновление сервер успевает только при старте, поэтому новый набор включится со следующего перезапуска после обновления Viewpoint. Принудительно выбрать набор можно через `VIEWPOINT_COMPAT=legacy|current` в `.env`.
- **Готов к 0.1.7 по коду:** ни один из наших аддонов (Viewpoint - Roofs, единственный с такой проверкой в коде, убран 5 ноября 2026).
- **Больше всего риска:** Java-аддоны, которые лезут во внутренности Viewpoint и написаны под 0.1.6:
  - Viewpoint Turbo: кэш шейдеров «для Viewpoint 0.1.6/0.1.6.1»;
  - Recoil & ADS: подстраивается под стрельбу 0.1.6;
  - Vehicle Interiors: по пересказу его описания на зеркале top-mods сделан строго под 0.1.6.1. В коде проверки версии не нашлось.
  - Viewpoint - Visceral: у него, как у самого Viewpoint, `versionMax=42.21`, и он патчит рендер и шейдеры Viewpoint.
  - Project Real Limbs: Java-патчи анимации и попаданий, в том числе в Viewpoint.
  - Viewpoint - Physics & Collision: патчит модели, сборку объектов и столкновения Viewpoint.
  - Surface Fix и Immersive Driving (добавлены 5 ноября 2026): патчат внутренние классы Viewpoint (меш мира, шейдеры, камеру). Surface Fix выложен с исходниками «для разработчика Viewpoint», так что его исправления могут войти в 0.1.7, как вошёл Isometric No More.

  Если после обновления что-то из этого ломает игру, временно уберите мод через `MODS_DISABLED=...` в `.env` и выполните `docker compose up -d`.
- **Косвенный признак:** автор QOL собрал коллекцию «моды, которые хорошо идут с Viewpoint 0.1.7 (nightly)» ([2690796635](https://steamcommunity.com/workshop/filedetails/?id=2690796635)). Из нашего пака в ней Recoil & ADS, True Ballistics, Advanced Throwables, 6282 models, Better Holsters & Belts, Alice's Weapon Sling и Fluffy Hair. Это подборка, а не тест совместимости: остальных наших модов там нет, но это не значит, что они ломаются.
- **Меньше риска:** True Ballistics, Interface, Advanced Throwables, Immersive Effects, Advanced Flashlight, Death Cam, Living Props, Visible Helicopter Events, UH-1 Huey Viewpoint Support. У них есть Java-часть, но привязки к версии в коде нет. Как они поведут себя на 0.1.7, неизвестно.
- **Почти без риска:** чистые пакеты моделей (6282 models, Visible Loot, Curtains, Windows, Fences, Holsters & Belts), шейдерпак Silent Viewpoint Enhanced и все моды без Viewpoint.

Отдельно: у самого Viewpoint `versionMax=42.21`, так что обновление игры до 42.22 он не переживёт, пока автор его не обновит.

## Обслуживание

Все команды выполняются в папке проекта: в PowerShell на Windows, в терминале на Linux (там с `sudo`).

| Что | Команда |
| --- | --- |
| Логи сервера | `docker compose logs -f pz-server` |
| Остановить / запустить | `docker compose stop` / `docker compose up -d` |
| Перезапустить (заодно обновит игру и моды) | `docker compose restart pz-server` |
| Показать пароли | `docker compose run --rm pz-init passwords` |
| Выдать комплект вручную | `docker compose run --rm pz-kit ИмяИгрока` (без имени — список игроков онлайн) |
| Вызвать вертолёт (админ в игре) | `/chopper` в чате: летит к случайному игроку; `/chopper stop` — убрать |
| **Бэкап мира** | `docker compose run --rm pz-backup` → файл в папке `backups/` |
| Восстановить бэкап | `docker compose stop pz-server`, затем `docker compose run --rm pz-restore pz_ДАТА.tar.gz`, затем `docker compose up -d` |
| Применить правки репозитория (настройки, моды, новая версия) | `docker compose up -d --build` |
| Команда серверу через RCON | `docker compose exec pz-server bash -c 'rcon -a "$(hostname -i):$RCON_PORT" -p "$RCON_PASSWORD" players'` |

- **Бэкап** — архив всего мира: конфиги, сейв, аккаунты, пароли. Хранятся 7 последних. Если сервер запущен, перед архивом мир сохраняется по RCON. PZ ещё сам делает zip-бэкапы раз в 6 часов внутри тома.
- **Восстановление** сначала само архивирует текущий мир в `backups/pre-restore_*.tar.gz`.

### Как поменять настройки

| Что | Где | Когда применяется |
| --- | --- | --- |
| Пароли, память, порты, PVP, слоты | `.env` (скопируйте из `.env.example`) | `docker compose up -d --build` |
| Остальные параметры сервера | `server.env` | то же |
| Список модов | `mods.env` (`MOD_IDS` и `MOD_NAMES`, порядок важен) | то же; недостающие моды докачает `pz-init` |
| Опции сервера (приветствие, античит, карта игроков…) | `config/server.ini` | применяется при каждом запуске |
| Правила мира и точки спавна | `config/SandboxVars.lua`, `config/spawnregions.lua` | при каждом запуске ([подробнее](config/README.md)) |
| Комплекты снаряжения | `config/kits/<профессия>.txt` (например, `insurgent.txt`; формат и случайные группы `pick` описаны в шапке файла) | автовыдача — после `docker compose up -d`; ручной `pz-kit` — сразу |
| Облёты вертолёта | `HELI_FLYOVER_DAYS` в `.env` (см. `.env.example`) | `docker compose up -d` |
| Временно отключить моды (для проверки) | `MODS_DISABLED=Мод1;Мод2` в `.env` | `docker compose up -d` |

### Перенос на другую машину

1. На старой машине: `docker compose run --rm pz-backup`.
2. Скопируйте свежий файл из `backups/` в папку `backups/` проекта на новой машине.
3. На новой машине:
   ```bash
   docker compose up -d --build               # первый запуск: скачает игру и моды
   docker compose stop pz-server
   docker compose run --rm pz-restore pz_ДАТА.tar.gz
   docker compose up -d
   ```

Мир, аккаунты игроков и пароли переедут вместе с архивом.

## Особенности B42 и статус проверки

**Подводные камни, которые уже обойдены в этой сборке:**
- Ветки `unstable` больше нет: B42 вышла в `public` (42.20+). `BETA_BRANCH` пустой.
- `MapAllKnown` в 42.21 действует только в одиночной игре. Карта игрока на сервере строится из его записи на сервере (`WorldMapVisitedServer`), а она начинается пустой и заполняется только там, где игрок прошёл (±25 клеток) или прочитал карту. Это видно по коду 42.21, поэтому всю карту в эту запись отмечает `scripts/pz_map.lua`.
- В ini B42 нет ключей `AntiCheatProtectionType*`, вместо них `AntiCheatSafety`, `AntiCheatSpeed` и т.д. Шкала `MapRemotePlayerVisibility` тоже изменилась: 4 означает «все».
- В Sandbox B42 другие ключи: лут — `*LootNew` (дробные множители), опыт — `MultiplierConfig`, `Version = 6`. Ключи B41 сервер молча выбрасывает.
- `_SandboxVars.lua` сервер пишет только при создании мира. Без шаблона образ при каждом старте заново гоняет «прогон для генерации конфигов». Поэтому `pz-init` подкладывает шаблоны заранее.
- Образ ставит `-Xms` равным `-Xmx`, а ZGC в B42 тогда сразу занимает всю кучу как разделяемую память. Поэтому есть `MIN_MEMORY` и `SoftMaxHeapSize`.
- Образ дописывает в ini ключ без перевода строки и склеивает строки. Это починено в `config_editor.py`.
- Агент ZombieBuddy нельзя передавать через `JAVA_TOOL_OPTIONS`: лаунчер PZ запускает вспомогательную Java без классов игры, и агент её роняет. Агент вписывается в `vmArgs`.
- Встроенный загрузчик Workshop у сервера медленный (~100 КБ/с), поэтому моды заранее качает `pz-init` через SteamCMD.
- Новые тома Docker принадлежат root, а сервер работает под UID 10000. `pz-init` выставляет права сам.

**Проверено:**
- *На Linux-ВМ (B42.21.0, образ v1.1.1, ноябрь 2026), в предыдущей раскладке с папками вместо томов:*
  - сервер запускается со всеми 45 Mod ID, ошибок «мод не найден» нет;

  - снаружи отвечают 16261/udp (Steam-запрос: `hidden;modded;pvp`) и 16262/udp (RakNet).
- *Текущая схема:*
  - образ собирается;
  - логика `init.sh` и `server.sh` проверена вне Docker: пароли генерируются один раз и не меняются при повторном запуске, шаблоны раскладываются только при первом запуске, Windows-переносы строк убираются, настройки `server.ini` применяются повторно без изменений, команда SteamCMD собирается правильно, агент включается, когда мод скачан.
